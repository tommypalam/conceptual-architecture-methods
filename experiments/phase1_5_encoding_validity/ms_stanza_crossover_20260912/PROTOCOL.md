## Analysis fixed before responses

Primary family: four two-sided Fisher exact tests at MS=.9, Holm correction
across all four, alpha .05. Compare P2 minus canonical MS stanza within each
fixed background, and P2 minus canonical background within each fixed MS
stanza. The .9 focus follows the prior high-value divergence; no test selected
from these new results. Report all four risk differences, including null or
opposite results, with conservative nominal 95% exact intervals. These
intervals are not family-adjusted; significance uses the Holm tests.

Secondary: high-minus-low endpoint effects for all four compositions and the
high-value difference-of-differences (P2/P2 - P2/C - C/P2 + C/C, background first).
Report conservative nominal 95% intervals; no secondary significance rule.
Two levels do not test monotonicity or the original five-level gradient gate.
There is no combined success threshold, optional extension, pooling or
post-result selection of a winning prompt.

## Meaning and limits

Existing MS/S2 directional hypothesis is retained, but broad moral scope is not
synonymous with formal reporting. The decomposition estimates wording-block
effects conditional on the other block. It does not separate semantic content,
lexical emphasis and length within a block. Lack of detection at N20 is
inconclusive, not invariance. A difference-of-differences point estimate alone
does not establish interaction. Selection followed earlier results and these
are exploratory mechanism diagnostics, not a fresh full validity battery.
The original 8/30 versus 24-required gate remains unchanged; Phase 2 stays held.
