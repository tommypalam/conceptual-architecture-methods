# Phase 1.5 evidence index

[Back to Phase 1.5](README.md) | [All experiments](../README.md)

Studies are grouped by their purpose. Descriptive link labels make them easier
to find; the recorded folder names remain unchanged. Start with the final
evidence, then use the earlier studies to trace how the findings developed.

Each entry is a package or designation, not a claim that its planned collection
completed. Consult its protocol and report for execution status. Recovery
snapshots overlap other files; do not count or pool them as new observations.
