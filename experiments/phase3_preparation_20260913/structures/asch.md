# Asch: structural review packet

Status: draft. No validated canonical or decanonised prompt is released.

## Behaviour to measure

Share of critical perceptual trials matching the incorrect majority; cluster repeated trials by participant.

## Actors

- participant
- scripted peers giving perceptual judgments
- experimenter

## Required structure

- Objectively distinguishable reference and alternatives
- Unanimous incorrect peer answers before participant responds
- Correct option and majority option counterbalanced without revealing that peers are scripted

## Candidate settings from the spec

Canonical: Line-length matching under unanimous majority pressure.

Decanonised: Product colour matching in a marketing setting (spec example).

## Independent review questions

- Supplying the correct answer in prose changes a perception task into an instruction conflict
- Colour and line judgments need controlled stimuli and competence checks
- A single hypothetical response is not the original repeated-critical-trial measure

Preserve agency, information, incentives, pressure, available actions, timing and
outcome measurement. Reject a variant that changes a load-bearing element.
Do not include target human percentages in prompts shown to simulated agents.
