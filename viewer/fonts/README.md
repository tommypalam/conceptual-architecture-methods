# Local interface fonts

Lilita One supplies the game-style display lettering; Nunito supplies controls
and recorded text. Both font binaries are unmodified, served locally, and
licensed under the accompanying SIL Open Font License 1.1 texts. No font
requests go to an external service during playback.

Sources: [Lilita One](https://github.com/google/fonts/tree/main/ofl/lilitaone)
and [Nunito](https://github.com/google/fonts/tree/main/ofl/nunito).
The manifest records downloaded source URLs, byte sizes and SHA-256 hashes.
