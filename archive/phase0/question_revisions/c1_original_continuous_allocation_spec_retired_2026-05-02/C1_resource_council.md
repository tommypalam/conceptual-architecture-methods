# C1 - The Resource Council

**Archive source:** Original C1 allocation-spec prompt before binary respec on 2026-05-02.

**Diagnosis:** The original "allocate EUR 500,000 across four categories" design is too continuous/averaging-prone for Phase 0 baseline calibration. It measures budget smoothing and consensus style more than a clean response distribution. C1 was respecified as a binary choice between two complete budget packages so calibration can target PACKAGE_A / PACKAGE_B while preserving the all-five-concepts Resource Council structure.

```
Five senior managers at a mid-sized pharmaceutical company must allocate a discretionary budget of EUR 500,000 across four categories. They must reach consensus; failure to reach consensus defaults to an equal 25% split.

Allocation categories:
- R&D acceleration (innovation, future capacity)
- Employee bonuses (distributive justice, recognition)
- Community social-responsibility programme (care, external moral scope)
- Operational cost-reduction reserve (institutional security, procedural prudence)
```
