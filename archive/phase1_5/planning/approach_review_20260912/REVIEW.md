Pause the proposed repeated-block study and further API probes. All collected

## The objective and the evidence are different things

The objective is a ten-parameter ethical profile that causally influences an
agent's decisions in a distinguishable, interpretable way. The behavioural
battery cannot establish subjective understanding or an AGI claim by itself.
The thesis expressly limits its claim (opening scope and section4).

What survives: canonical MoR/S3 has a graded original response and the same
endpoint direction in six studies. What remains open: interpretation/recovery,
representation retention, wording transport, interactions and repeatability in
some contexts. The MS replay shows changing seeds alone is insufficient to
explain the discrepant counts; it does not establish a server fault or require
deterministic decisions from a stochastic model.

Repeatedly asking whether one MS cell returns its previous rate cannot resolve
all of these questions. Likewise, selecting the best observed wording or an
outcome-replacing decision filter would not establish the intended encoding.

## Route A: revisit the encoding mechanism

Thesis4.1 explicitly describes system prompting as the baseline and tool-based
injection as a target. Fine-tuning is rejected there as the primary approach;
do not introduce it casually as the next step. Accepted Phase0 closure and
later operational decisions remain authoritative over historical task lists.

A mechanism review should compare the existing tool screen against the target
contract before building another implementation:

- One agent remains one fixed, hash-locked ten-dimensional profile. A tool query
  must not silently redraw a new agent or change a parameter.
- Canonical definitions and numeric values remain inspectable. A typed profile
  interface is a candidate representation, not a proven semantic improvement.
- The profile service should have no access to action labels or the dilemma,
  and should not score, replace or prescribe a decision. The model must make
  the choice. No manually invented parameter-to-action rules.
- Serialization/retrieval and semantic use are separate tests. Passing a
  mechanical interface contract is necessary but does not establish encoding.
- The previous tool screen delivered the full text through a forced tool call
  and reduced MoR sensitivity. Any proposed design must identify its substantive
  difference and a discriminating test; another wrapper is not sufficient.

This route is a design proposal only. No new adapter, prompt, tool schema,
parameter mapping or paid test has been approved or implemented here. New
meaning departures require a concrete limitation and discussion under the
constitution; no departure is presumed necessary.

## Route B: revisit the evaluation strategy

Keep the current encoding fixed and distinguish parameter influence from
wording and collection variation using all retained evidence. Specify the
statistical unit and uncertainty before more data: individual decisions may
vary while population-level effects are reproducible. Avoid treating a
same-seed individual mismatch as automatic invalidity.

Any new predictive or hierarchical analysis would be retrospective/exploratory;
held-out splits must keep repeated prompt groups and collection blocks together
as appropriate. It cannot substitute for the frozen original battery or convert
8/30 equivalence cells into a pass. A revised gate requires an explicit,
reviewable rationale and researcher discussion, not a new threshold chosen to
fit these results. No evaluation rule is changed by this memo.
